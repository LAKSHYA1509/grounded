# repo that worked last week and doesn't today - these libraries move fast.
#
# These exact versions are verified working on Python 3.13.
#
# NOTE ON THE PINS: an earlier attempt pinned older versions, which resolved
# to a chromadb that constrained numpy below the first release with cp313
# wheels. pip then tried to BUILD numpy from source, needed a C compiler,
# and failed. If installation ever breaks that way on a newer Python, that
# is the thing to look for - a transitive constraint holding a compiled
# package below its first wheel for your interpreter.
